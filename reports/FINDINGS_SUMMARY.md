## 📝 问题详细列表

### 🔴 严重问题（需立即修复）

#### 1. API 密钥硬编码暴露
```
位置: bridge_server.py:20, full_pipeline.py:8-9
风险等级: 🔴 严重
影响: API 密钥被盗用，产生费用和安全风险
修复时间: 1 小时
修复方式: 
  1. 立即轮换密钥
  2. 迁移至环境变量
  3. 更新所有部署环境
验证方式: grep -r "sk-" . --include="*.py"
```

#### 2. 患者数据仅存内存（无持久化）
```
位置: bridge_server.py:38-40
风险等级: 🔴 严重
影响: 服务器重启丧失所有患者数据和聊天记录
医学合规: 违反患者信息保护要求
修复时间: 2-3 天
修复方式:
  1. 集成 PostgreSQL 数据库
  2. 实现 ORM（SQLAlchemy）
  3. 迁移现有数据
  4. 设置定期备份
验证方式: 测试服务器重启后数据是否保留
```

#### 3. CORS 过度宽松
```
位置: bridge_server.py:99 (_cors 方法)
风险等级: 🔴 严重
影响: 任何域都可跨域访问 API，易被恶意使用
修复时间: 30 分钟
修复方式:
  1. 使用白名单限制域名
  2. 从环境变量加载允许的源
  3. 针对不同端点设置不同规则
验证方式: curl -H "Origin: http://evil.com" ...
```

#### 4. 无请求大小限制（DoS 风险）
```
位置: bridge_server.py (do_POST 方法)
风险等级: 🔴 严重
影响: 攻击者可发送超大请求，导致服务崩溃
修复时间: 1 小时
修复方式:
  1. 添加 Content-Length 检查
  2. 实现请求队列限制
  3. 添加速率限制
验证方式: curl -X POST --data $(python -c 'print("x"*100000000)') ...
```
