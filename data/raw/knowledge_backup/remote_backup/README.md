### 批量获取结果

通过 `GET /precise_json?disease={病名}&plan=oral_decoction` API 批量查询 679 个有口服方案标记的疾病：

- **成功**: 674 疾病
- **失败** (远程未匹配)：亨特综合征、乳腺结核、声带小结 / 声带息肉、浆细胞性乳腺炎、肝脏囊性疾病

### 数据特点

- 数据结构不统一（4 种嵌套模式），但均为治疗级结构化数据
- 每个证型通常包含：`加减`（症状条件→药名(g)[药理靶点]）、`方剂`（基础方名）、`组成`（每味药 名称(g)[药理作用|功效]）
- 加减规则中包含西医指标（CRP、PCT、WBC、SpO₂、eGFR 等）驱动的精准用药
- 药理注释详细（含分子机制：如"[扩张支气管平滑肌|增加分泌以稀释痰液]"）

### 数据质量

- 远程数据是最高质量的治疗级知识库，每味药的药理作用有明确标注
- 含西医临床指征、中医指征和推理解释
- 部分疾病有跨证型通用加减（针对共病/伴随指标异常）
- 数据完整性：部分疾病缺少 `方剂` 和 `组成` 字段（空字符串或只含 `加减`）
