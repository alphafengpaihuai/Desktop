# M3 临床药学审核与处方净化模块实现指令（循证安全版）
## 总体原则
- M3 是处方交付患者前安全防线。
- 所有审核规则基于预先构建的药学知识库，模型仅负责规则匹配与冲突检测，不生成新的药学知识。
- 审核结果必须可追溯至具体规则条目。
- 审核不通过时，必须明确阻断原因和修正建议，返回 M2 修改。
- M3 不负责辨证、不负责选方、不负责加减，只审核已生成处方的安全性与合理性。
## 输入
- M2 输出的完整处方：
- 方剂名称、出处、证据层级
- 每味药物的名称、剂量、炮制、角色（君/臣/佐/使）
- 加减药物及加减依据（靶点/机制、证据等级）
- M1 输出的患者档案：
- 年龄、性别、
- 西医诊断
- 生命体征（血压、心率、体温、血氧）
- 理化指标（肝肾功能、电解质、凝血功能等）
- 过敏史、既往史、合并用药（西药）
- M2 输出的复诊决策（如适用）：
- 四象限定位（Q1/Q2/Q3/Q4）
- 守方/调整/更方标记

# M3 临床药学审核与处方净化模块实现指令（精简安全版）
## 总体原则
- M3 是处方交付患者前的最后一道安全防线。
- M3 不判断寒热虚实、不判断君臣佐使——这些是 M2 的工作，M2 已经完成了。
- M3 只做三件事：
  1. 审核药物安全性（十八反、十九畏、明确毒性药物）
  2. 裁剪药味过多（从边缘药物开始减）
  3. 调整剂量过大（超药典上限的拉回安全范围）
- 结果必须可追溯至具体规则条目。
- 审核不通过时，明确阻断原因和修正建议，返回 M2 修改。

## 输入
- M2 输出的完整处方（药物、剂量、炮制）
- 患者年龄、体重、生命体征、理化指标、合并西药
- M1 输出的西医诊断

## 药味数标准
- 成人：16 味左右，20 味为硬上限
- 儿童：16 味为硬上限
- 超过硬上限时触发裁剪，从边缘药物开始减

## 审核流程

### 前置安全网：绝对危急阈值自动升级
若患者数据中存在以下任一，系统强制升级为"急"：
- 血压 ≥ 180/110 或 收缩压 ≤ 80 mmHg
- 心率 ≥ 130 或 ≤ 45 次/分
- 体温 ≥ 40℃
- SpO₂ ≤ 90%
- 主诉包含：急性胸痛、意识下降、大出血、重度呼吸困难
升级后，禁用温阳、破血、含钾药物等。

### 第一级：十八反、十九畏检查
- 逐对检查处方中是否存在十八反、十九畏组合
- 命中 → 阻断，返回 M2 修改
- 检查依据：药典十八反十九畏列表

### 第二级：毒性药物剂量审核
- 检查处方中是否含有毒性药物（参考药典毒性中药列表）
- 逐项核对：
  - 剂量是否超药典上限
  - 是否需特殊煎法（先煎、久煎）
  - 是否有减毒配伍
- 超量 → 强制拉回安全范围或阻断

### 第三级：西药交互检查
- 若患者有合并西药，检查中药-西药相互作用
- 严重交互 → 建议间隔服药或禁用
- 中等/轻微 → 输出警告，建议监测

### 第四级：药味数极值裁剪
- 成人超 20 味、儿童超 16 味时触发
- 裁剪优先级：
  1. 先减佐/使药（非君臣、非 RAG 来源）
  2. 再减靶向非主诉症状的药物
  3. 仍超限时，优先保留经典药对中的核心药物
- 每次裁剪记录原因

### 第五级：剂量调整
- 检查每味药的剂量是否超药典常用范围
- 超范围 → 拉回常规上限
- 儿童按体重/年龄折算
- 老年人酌减

## 关键规则
2. 十八反十九畏 → 触发即阻断
3. 毒性药物超量 → 强制拉回或阻断
4. 药味超限 → 从边缘药物开始减，如生姜、大枣一类。
5. 剂量超药典 → 拉回上限
6. 所有动作必须记录，可追溯
### 第四级：最终处方生成与格式化输出
- 综合以上所有步骤，生成净化处方。
- 输出完整处方文本（临床可读格式，每行4味药）。
- 输出处方净化修正记录，列出每步剔除/修改动作及理由。
- 若在任一阶段触发阻断，输出阻断信息并建议返回M2修改。
## 西药冲突检测（新增）
- 读取患者合并用药（西药），检查中药-西药相互作用。
- 交互类型：
- 药效协同（可能导致过量）
- 药效拮抗（可能导致失效）
- 代谢竞争（肝酶CYP450）
- 毒性叠加（肝肾损伤、出血风险）
- 建议：间隔服药时间、监测指标、减量或禁用。
## 毒性药物专项审计
- 检查处方中是否含有毒性药物（参考药典毒性中药列表）。
- 逐项核对：
- 剂量是否在安全范围内
- 疗程是否超限
- 是否需特殊煎法（先煎、久煎等）
- 是否有减毒配伍（甘草、生姜、大枣等）
- 是否需监测肝肾功、电解质、凝血等
- 若超标，强制减量或阻断。
## 特殊人群剂量调整
- **儿童**：按年龄/体重折算，注意器官发育未成熟。
- **老年人**：肝肾功能减退者酌减，注意多药联用风险。
- **孕妇/哺乳期**：严格限制，避免致畸/致流产药物。
- **肝肾功能不全**：避免肝肾毒性药物，调整剂量。

## 关键规则汇总
1. 所有审核规则来自知识库，模型不生成新规则。
2. 审核不通过必须阻断，并给出明确的修正建议。
3. 所有剔除/保留动作必须记录，做到有据可查。
4. 方向一致性裁剪不得误删有 RAG 循证依据、经典反佐或临床决策豁免的药物。
5. 毒性药物必须给出安全剂量范围和监测建议。
6. 西药交互风险必须检测并给出处理建议。
7. 特殊人群剂量必须调整（儿童、老人、孕妇、肝肾功能不全）。
8. 与 M2 对接：审核通过则交付处方；阻断则返回 M2 修改。
